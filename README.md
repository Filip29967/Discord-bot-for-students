# Projekt OI

Celem projektu jest stworzenie chatbota na platofmie dicord pomagającym organizacje czasu studenta.

## Cele (co ma robić)
- wyświetlać plan dla każdego indywidualnie
- porównywać plany między studentami, żeby sprawdzić kiedy jest czas wolny między zajęciami
- umożliwiać tworzenie tasków i przypominać o nich

## Użyte narzędzia

- C#
- jakaś baza danych
- git
